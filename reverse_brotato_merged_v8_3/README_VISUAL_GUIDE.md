# 这张战场到底在干什么？

这个项目是“哥布林指挥官：反向幸存者”。你不是中间拿剑的勇者，而是底部的哥布林指挥官。

## 画面图例

- **勇者**：中央拿剑、脚下红色圆环的角色。上方两条条：灰蓝是护甲，红色是生命。
- **红色大圆圈**：部署禁区，不是攻击范围。你不能把怪物直接丢到勇者脸上。
- **你的指挥台**：画面下方的木制平台和绿色哥布林，必须保护它。
- **你的怪物**：都带绿色地面圆环和绿色血条。战士、弓手、史莱姆、炸弹、萨满、食人魔的轮廓不同。
- **爆炸桶**：橙色木桶。攻击或触发后会爆炸。
- **减速泥**：半透明绿色水洼，角色经过会受到影响。
- **路障**：箱子状物件，会挡住勇者路线，也可以被打掉。
- **鼠标旁小圆**：准备部署的位置预览。绿色代表可以放，红色代表不可以。

## 一局里你要做什么？

1. 准备阶段，选择右侧兵种。
2. 在绿色边框内点击部署怪物，避开勇者红圈。
3. 按“开始战斗”。
4. 怪物会自动攻击勇者。勇者会先打怪物，没怪物时打你的指挥台。
5. 击败勇者，拿奖励，进入下一波。

## 为什么之前像一团看不懂的圆？

原版是“先把玩法跑起来”的程序绘制占位版本。视觉上没有明确角色剪影，也没有为桶、泥潭、禁区写标签，所以功能存在，但阅读成本很高。本版只改了外观和提示，不改原有玩法逻辑。
