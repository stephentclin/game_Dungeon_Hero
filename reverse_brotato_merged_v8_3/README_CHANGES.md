# 本次可读性与红按钮改动

- 第一波变成训练波：只开放战士，场地会直接提示「部署」与「开始战斗」。
- 绿色边框现在就是实际可部署区域，避免点到 UI 遮挡区后被拒绝。
- 鼠标预览会显示所选单位的名称、指挥点成本和攻击范围。
- 勇者会用细红线指向当前目标，便于看懂他在追谁。
- 红按钮不再因为勇者血量过高或第二次满怒而直接结束游戏。每局可安全使用一次。
- 选项 1 改为「战术空投」：4 秒眩晕、+70 指挥点、接下来 3 次部署免费。它不再要求玩家在 5 秒内疯狂点击。
- 选项 2 改为「破甲重炮」：45 点无视护甲伤害、击碎 70% 剩余护甲、眩晕 2 秒。它的数值效果和描述一致，并能触发破甲狂暴。

## 运行

在 Godot 中导入 `project.godot`，按 F5。第一次要重新体验训练波时，删除 Godot 用户数据中的 `goblin_commander_save.json` 即可；不过训练波的规则不依赖存档。


# 五命胜利目标改动

- 勇者不再在第一次死亡后让一局结束：他每次倒下会消耗 1 条命并在下一波复活。
- 本局需要击败勇者 **5 次** 才能胜利。
- 顶部标题右侧新增「勇者余命 5/5」小条，5 个红色格对应 5 条命，会在每次击败后熄灭一个。
- 每次非最终击败会显示「当前余命 x/5」，并仍给出波次奖励和临时强化。
- 第 5 次击败会直接显示最终胜利界面，并发放该次的最终奖励。
