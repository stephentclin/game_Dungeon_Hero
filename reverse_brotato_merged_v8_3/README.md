# 哥布林指挥官：反向幸存者

Godot 4.x / GDScript 制作的 2D 俯视角可玩原型。玩家不是勇者，而是哥布林指挥官：在竞技场召唤怪物、拖住并击败会不断复活并变强的勇者。

## 运行方式

1. 安装 Godot 4.x。
2. 用 Godot 打开本目录的 `project.godot`。
3. 运行主场景 `res://scenes/Main.tscn`。

命令行运行示例：

```powershell
godot --path .
```

## 操作方式

- 数字键 `1` 到 `6`：选择兵种。
- 鼠标左键：点击绿色召唤格部署已选择怪物。
- `Space`：开始当前波次战斗。
- `R`：怒气满时触发红按钮。
- 右侧面板：选择兵种、查看属性、解锁和永久升级。

## 已实现核心规则

- 单屏俯视角竞技场。
- 准备阶段和战斗阶段。
- 指挥点部署系统，战斗中指挥点缓慢恢复。
- 6 种数据驱动怪物：战士、弓手、史莱姆、炸弹小鬼、巫毒萨满、食人魔。
- 勇者自动寻找怪物，没有怪物时攻击指挥台。
- 怪物自动追击或远程攻击勇者。
- 勇者生命与护甲双条机制。
- 护甲粉碎事件：全体存活怪物狂暴、屏幕震动、指挥点奖励、怒气下降。
- 怒气系统：随时间、怪物死亡、勇者接近指挥台上升，压制勇者时下降。
- 红按钮系统：第一次安全触发可三选一，第二次满值或勇者生命过高会失败。
- 红按钮效果：紧急部署、大导弹、哥布林弹射决斗。
- 五命胜利目标：勇者每次倒下消耗一条命；耗尽 5 条命后，玩家获得最终胜利。
- 顶部「勇者余命」小条：用 5 个红色生命格显示勇者当前剩余命数。
- 每次击倒后的奖励：金币、技能点和三选一临时强化。
- 永久解锁与永久升级保存到 `user://goblin_commander_save.json`。
- 全兵种解锁后，金币按 `BalanceConfig.GOLD_TO_SKILL_POINT_RATE` 转换为技能点。
- 场景互动物：爆炸桶、黏液地面、临时障碍物。
- 简单对象池：常见怪物、子弹和伤害数字复用，避免频繁创建销毁。

## 主要文件

- `scenes/Main.tscn`：入口场景。
- `scripts/Main.gd`：主流程、波次、部署、奖励、失败和红按钮编排。
- `scripts/Hero.gd`：勇者 AI、护甲、生命、状态和攻击。
- `scripts/Monster.gd`：怪物 AI、攻击、特殊能力和狂暴。
- `scripts/PlacementSystem.gd`：召唤格绘制与点击部署。
- `scripts/RageSystem.gd`：怒气变化与满值事件。
- `scripts/RedButtonSystem.gd`：红按钮触发规则。
- `scripts/WaveDirector.gd`：勇者强化、奖励和临时强化抽取。
- `scripts/SaveSystem.gd`：永久进度保存与读取。
- `scripts/UIController.gd`：基础 UI、奖励、失败、红按钮和决斗界面。
- `scripts/data/BalanceConfig.gd`：集中数值配置和数据创建。

## 手动验收建议

1. 启动后应进入准备阶段，并显示勇者本波属性与强化。
2. 选择兵种，点击绿色召唤格，应消耗指挥点并部署怪物。
3. 开始战斗后，怪物会自动攻击勇者。
4. 勇者会优先攻击怪物，没有怪物时攻击指挥台。
5. 打爆护甲后，应出现“护甲粉碎”提示，存活怪物变为狂暴。
6. 击败勇者后，应出现胜利奖励和三选一临时强化。
7. 使用金币解锁萨满或食人魔，重启后解锁应保留。
8. 怒气满且勇者生命低于 80% 时，应出现红按钮三选一。
9. 第一次红按钮后怒气回到 50，第二次满值应失败。
10. 选择“哥布林弹射决斗”应进入回合制决斗界面。

## 当前简化

- 美术、音效和特效均为程序生成占位表现。
- 寻路使用“朝目标移动 + 简单障碍检测”，没有复杂导航网格。
- 红按钮决斗是轻量回合制模型，尚未做完整技能树。
- 地图固定，尚未加入随机地形和关卡编辑。
- 怪物升级为统一百分比提升，后续可改为每个兵种独立升级树。

## 下一步最值得加入的 3 项功能

1. 为 6 个兵种各自加入分支升级树和更明确的协同标签。
2. 加入更多可部署陷阱，让玩家在怪物之外也能改变勇者路线。
3. 增加一套更清晰的战斗回放/统计界面，帮助玩家理解哪种部署最有效。



## 五命胜利规则

- 一局开始时，勇者有 **5 条命**。
- 每次生命值归零，他会消耗 1 条命，玩家获得本波奖励，并在下一波面对复活且更强的勇者。
- 顶部右侧的 **「勇者余命 5/5」** 小条会实时显示剩余命数。
- 当余命变为 `0/5`，玩家立刻获得最终胜利，不再进入奖励三选一。
