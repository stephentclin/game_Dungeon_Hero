# v8.2 UI polish

- Removed the top-right gear shortcut from the main menu. Settings is now entered only through the large purple Settings button.
- Refined the in-game HUD:
  - top-left: Hero Intel, life pips, active seals, hero HP, armour and command-post HP;
  - top-centre: wave/hero level, resources, rage and command points;
  - right side: unit growth panel remains unobstructed;
  - bottom-right beside the goblin post: a clearer command panel with selected unit and combat controls.
- Increased HUD panel contrast, shadows and gold edging.
- Button labels now nudge down briefly when pressed, matching the pressed button artwork for a more tactile feel.
